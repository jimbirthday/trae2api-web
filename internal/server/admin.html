按模型用量统计

Token 与缓存率为全量精确（取自每个请求的 token_usage 事件）； 「积分/百万」为窗口采样估算——上游只提供账号级累计计数器且异步结算， 因此按「一个窗口内的积分增量 ÷ 同窗口 token 总量」计算，再按 token 比例分摊到模型， 取多次样本的中位数抗离群。样本数见末列，样本为 0（刚启动或窗口未满）时显示 "-"。
整体口径：缓存率 = 全部模型 cache_read ÷ prompt（加权）；积分/百万 = 全部分摊积分 ÷ 全部 token（加权）。
